MATRIX WORKBENCH

답만 확인하지 말고,
행 연산을 따라가세요.

2×2~6×6 행렬의 행렬식, 역행렬, 계수와 해 공간을 정확한 분수로 계산합니다.

01행렬 입력

행은 줄바꿈, 값은 공백·쉼표·세미콜론으로 구분하세요. 정수, 소수 6자리, a/b 분수를 허용합니다. 지수 표기는 지원하지 않습니다.

Ax=b를 풀려면 행렬 크기와 같은 개수의 값을 입력하세요. 비워두면 행렬만 계산합니다.

03가우스–조던 행 연산

각 단계는 [A | I | b]를 표시합니다. b는 입력할 때만 포함됩니다. 최대 절댓값의 피벗을 선택합니다.

가정·한계·참고 자료

유리수 BigInt로 계산하며 분모 0과 비유한 표기를 거부합니다. 입력 절댓값은 1,000,000 이하, 분모는 1,000,000 이하입니다. 소수 입력도 정확한 유리수로 취급합니다. 소수 표시는 유효숫자 10자리 근삿값이며 계산에는 영향을 주지 않습니다. 단위는 입력에 지정하지 않는 무차원 수입니다. 연산 중 정수 1,000자리 상한을 적용합니다. 입력과 결과는 기기 안에서만 처리하며 새로고침하면 사라집니다.
