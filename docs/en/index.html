MATRIX WORKBENCH

Go beyond the answer.
Follow every row operation.

Compute determinants, inverses, rank and solution spaces for 2×2–6×6 matrices using exact fractions.

01Matrix input

Separate rows with newlines and values with spaces, commas or semicolons. Integers, decimals up to 6 places and a/b fractions are accepted. Scientific notation is not supported.

To solve Ax=b, enter as many values as the matrix size. Leave blank to analyze only the matrix.

03Gauss–Jordan row operations

Each step displays [A | I | b]. The b column appears only when supplied. The largest absolute pivot is selected.

Assumptions, limits and sources

Calculations use exact BigInt rational arithmetic. Zero denominators and non-finite notation are rejected. Absolute input values and denominators must not exceed 1,000,000. Decimal input is treated as an exact rational. Decimal display uses 10 significant digits and does not affect calculations. Values are dimensionless. Intermediate integers are limited to 1,000 digits. Inputs and results remain on your device and are cleared on refresh.
